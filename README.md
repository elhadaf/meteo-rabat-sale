# Météo Rabat‑Salé

Petite application web qui affiche chaque jour la météo de la région de Rabat‑Salé :

- conditions de l'heure en cours (température, ressenti, vent, humidité, UV, lever et coucher du soleil) ;
- courbe de température et risque de pluie heure par heure pour la journée ;
- prévisions sur 14 jours (min, max, pluie).

Les données viennent en direct de l'API gratuite [Open‑Meteo](https://open-meteo.com/) à chaque ouverture de la page, puis toutes les 30 minutes. Aucune clé ni serveur n'est nécessaire.

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche `main` (Settings → Pages → Deploy from a branch → `main` / root).
